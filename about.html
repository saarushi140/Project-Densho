The Crisis: The Expiration of Muscle Memory

We can digitize manuals, but we cannot digitize muscle memory. True expertise—the precise pressure of a master craftsman, the exact angle of an industrial tool—is locked in the physical realm. When veterans retire, decades of tacit knowledge vanish with them. Traditional video tutorials fail because they are passive; they lack 3D spatial geometry and offer zero real-time correction.

The Solution: Digitizing the Physical Blueprint

Project Denshō captures the physics of expertise. Using browser-based spatial AI, we extract real-time 3D telemetry from a standard 2D webcam feed. We transform raw movement into a replayable spatial ghost trail—allowing apprentices to physically align with the master's exact coordinates and synchronize their technique in real-time.

Technology Stack

Google MediaPipe

Powers the real-time hand tracking model, extracting 21 3D landmarks per hand directly in the browser via WebAssembly.

HTML5 Canvas API

Used for the HUD, rendering the Kintsugi-gold ghost trails, and overlaying the neural connections over the live video feed.

Tailwind CSS

Provides the utility-first CSS framework allowing for rapid prototyping of the Cyber-Zen dashboard interface.

Vanilla JavaScript (ES6+)

Handles the synchronization math, calculating the Euclidean distance between Master and Apprentice coordinates to generate the sync score.
